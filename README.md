# GEN1 Small Business Hero
Comic-book scrollytelling landing page for GEN1 Digital Services, focused on Main Street small businesses in Merced County.

## GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder to the root of your GitHub repository. Then enable Settings > Pages > Deploy from a branch > main > /(root).

## CTA
The current CTA uses `hello@gen1digitalservices.com` as a placeholder. Replace it with the desired booking link, form, phone number, or email before final launch.
